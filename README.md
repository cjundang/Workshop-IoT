# Workshop: Edge Computing and Artificial Intelligence of Things (AIoT)

## ส่วนที่ 1 การใช้งาน Raspberry Pi และ Linux

ในส่วนแรก ผู้เข้าอบรมจะได้เรียนรู้พื้นฐานของ Raspberry Pi ในฐานะอุปกรณ์ Edge Computing สำหรับระบบ AIoT พร้อมทั้งทำความเข้าใจระบบปฏิบัติการ Linux และการใช้งานผ่าน Command Line ซึ่งเป็นพื้นฐานสำคัญของการพัฒนาระบบแบบ Embedded และ IoT ผู้เรียนจะได้ฝึกใช้คำสั่ง Linux ที่จำเป็นสำหรับการจัดการไฟล์และโฟลเดอร์ การติดตั้งซอฟต์แวร์ การจัดการสิทธิ์ผู้ใช้งาน การเชื่อมต่อเครือข่าย การใช้งาน Python และ Virtual Environment ตลอดจนการเตรียม Raspberry Pi ให้พร้อมสำหรับการพัฒนาและติดตั้งระบบ AIoT ด้วยตนเอง โดยกิจกรรมในส่วนนี้มุ่งเน้นการลงมือปฏิบัติจริง เพื่อสร้างความคุ้นเคยกับสภาพแวดล้อมการพัฒนาบน Linux และเตรียมความพร้อมสำหรับการเขียนโปรแกรมและการสร้างระบบในขั้นตอนถัดไป

## ส่วนที่ 2 การเขียนโปรแกรม ESP8266 ผ่าน Linux Command Line

ในส่วนที่สอง ผู้เข้าอบรมจะได้เรียนรู้การพัฒนาโปรแกรมสำหรับบอร์ด ESP8266 โดยใช้ Arduino CLI บนระบบปฏิบัติการ Linux แทนการใช้ Arduino IDE เพื่อให้เข้าใจกระบวนการพัฒนาโปรแกรมแบบ Command Line ซึ่งเหมาะสำหรับการทำงานจริงและการพัฒนาแบบอัตโนมัติ (Automation) ผู้เรียนจะได้ติดตั้งเครื่องมือที่จำเป็น สร้างโปรเจกต์ คอมไพล์และอัปโหลดโปรแกรมไปยังบอร์ด ESP8266 ผ่านคำสั่งบน Terminal รวมถึงศึกษาการใช้งาน GPIO การอ่านค่าจากเซ็นเซอร์ DHT11/DHT22 การสื่อสารผ่าน Serial Monitor และการส่งข้อมูลในรูปแบบ JSON ผ่านเครือข่าย Wi-Fi ไปยัง Raspberry Pi ด้วยโปรโตคอล HTTP ซึ่งจะทำให้ผู้เรียนเข้าใจการทำงานของโหนดเซ็นเซอร์ในระบบ AIoT ตั้งแต่การเก็บข้อมูลจนถึงการสื่อสารกับเซิร์ฟเวอร์

## ส่วนที่ 3 การสร้าง Web Dashboard ด้วย Flask และ Web API บน Raspberry Pi

ในส่วนสุดท้าย ผู้เข้าอบรมจะได้พัฒนาระบบ Web Server บน Raspberry Pi โดยใช้ภาษา Python และ Flask Framework เพื่อสร้าง RESTful Web API สำหรับรับข้อมูลจาก ESP8266 จัดเก็บข้อมูลลงในฐานข้อมูล และพัฒนา Web Dashboard สำหรับแสดงผลข้อมูลอุณหภูมิและความชื้นแบบ Real-time ผู้เรียนจะได้เรียนรู้การรับส่งข้อมูลในรูปแบบ JSON การออกแบบ API การจัดเก็บข้อมูลด้วย SQLite หรือไฟล์ JSON รวมถึงการพัฒนา Web Interface ด้วย HTML, CSS และ JavaScript เพื่อดึงข้อมูลจาก API มาแสดงผลอัตโนมัติ เมื่อสิ้นสุดการอบรม ผู้เรียนจะสามารถพัฒนาระบบ AIoT แบบครบวงจร ตั้งแต่การอ่านข้อมูลจากเซ็นเซอร์ การสื่อสารผ่านเครือข่าย การประมวลผลบน Raspberry Pi ไปจนถึงการนำเสนอข้อมูลผ่าน Web Dashboard ที่สามารถนำไปประยุกต์ใช้กับงาน IoT และ Smart Environment ได้จริง
